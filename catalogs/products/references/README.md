# Source-backed product reference supplements

These supplements use the additive `product-reference.schema.json`. Product identity records remain in manufacturers/ and validate against the foundation or applicable draft family schema. Supplements reference those identities through subjectRef and preserve descriptive source observations without relaxing existing strict family schemas.

All observations are reference-only, not engineering-ready data. Browser pages were read on 2026-10-21 America/Toronto; source records use UTC retrieval timestamps. Original technical documents are linked, not redistributed. Source-byte hashes are null because exact document bytes were not acquired. No load tables are imported here. Missing dimensions, installation, approvals, code editions and capacities remain explicit gaps. Family references do not establish interchangeability, regional approval or current inventory.
