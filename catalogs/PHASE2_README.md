# Phase 2 — typed product schemas and discovery seeds

These are **draft** family-specific schemas and **discovery-only** source/product records. No numerical performance values, compatibility claims, approvals, or code implementation are asserted. Source URLs were supplied by the research report; they have not been freshly downloaded or hashed in this phase.

Before using records for engineering design: acquire exact source bytes, hash them, extract exact variant geometry and conditions, review code editions and approvals, cross-check table cells, and obtain independent engineering review. Source records are not product verification.

The product seeds intentionally contain no guessed geometry or capacity. Schema validates their identity envelope; family-specific engineering fields are optional until the record advances beyond discovery.
