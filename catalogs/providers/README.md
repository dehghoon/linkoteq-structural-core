# Vendor integration access — Canada first

This directory records **Linkoteq-authored integration metadata**, not manufacturer catalogue copies. Research date: 2026-10-22.

## Rules

- An accessible website, BIM download, eCatalog, SDK, or internal synchronization feature is **not** authorization for scraping, API use, or public redistribution.
- No API credentials or manufacturer-derived bulk catalogues in GitHub.
- No engineering design capacities may be treated as verified until official versioned documents and applicable code/jurisdiction are checked.
- Use a runtime provider and private permitted cache when the agreement allows it; preserve source, timestamp, code edition, units, and validity.
- Keep Canada-first product/code selection distinct from US-specific design rules.

## Vendor onboarding checklist

1. Simpson: request Hanger Selector API client credentials for NBCC 2020, production/staging access, licence terms, display/caching/project retention rights and quotas. Documentation: https://docs.strongtie.com/
2. Weyerhaeuser: request ForteWEB SDK via interoperability agreement; confirm Canadian product/code support and whether catalogue lookup is provided. https://www.weyerhaeuser.com/woodproducts/software-learning/forte-software/
3. Atkore/Unistrut: contact atkoretoolbar@atkore.com requesting authorized Canada/US product data feed, P1000/P3000 channels, fittings, UPC, geometry, load tables, approvals, updates and commercial usage rights. https://www.atkore.com/resources/bim-library-tools
4. Hilti: request separate Canadian product master/PIM engineering feed and usage rights; do not repurpose ON!Track customer asset API. https://www.hilti.com/content/hilti/W1/US/en/support/support/b2b-eprocurement/digital-procurement-ecosystems.html
5. Canam: request licensed Canada-specific joist/deck/Hambro geometry and engineering data interface; existing Revit/IFC resources are not a product API. https://www.canam.com/en/parametric-objects/
6. MiTek: request Canada Specifier product feed and licensing for connector geometry/capacity/code metadata. https://mitek.ca/software/

No vendor credentials, signed agreements, authenticated API calls, outreach submissions, or runtime adapters are claimed by this commit. All integration modes are discovery status only. Existing product records remain unchanged pending licence review.
