# Material reference templates

`material-templates-v05.json` is a lossless field migration of 22 templates from the pinned Linkoteq source identified in its provenance. Original uppercase IDs are intentionally preserved; these references are outside the product identity schema. Optional missing fields remain absent.

These are selection references, not Core v0.5 analysis-ready Materials. Consumers must obtain project-approved E, G, nu, rho and applicable design properties before creating canonical Materials. Standard editions are unspecified in the source. Canadian and US records remain distinct. No engineering properties, certification, or code compliance is asserted.
