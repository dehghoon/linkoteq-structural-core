# Linkoteq engineering catalogs — foundation

Additive catalogue layer for Core v0.5. `knowledge/` and the existing `registry/` are unchanged.

- `materials/`: reusable engineering materials.
- `sections/`: generic sections, including CISC/AISC and cold-formed.
- `products/`: manufacturer/brand-owned products and variants; category indexes are references, not copies.
- `systems/`: assembly roles, bill of materials, and source-backed compatibility.
- `performance/`: immutable code-edition-specific tables and conditions.
- `climate/`, `locations/`: future versioned geographic data.

A product is not a verified design result. A source-backed table is not a verified code implementation. Missing approval, compatibility, code edition, or verification evidence must not be inferred. Interpolation defaults to `none`. Vendor source URLs are metadata, not redistribution permission.
