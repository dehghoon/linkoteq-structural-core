## Private regression and measured performance

SCIENC is used locally and excluded from git. Counts are 2,949 nodes, 250 frames and 2,620 Areas. All Area boundary references resolve and no unconnected source nodes were found in the initial full connectivity audit. Section assignment counts match the supplied expectations. The raw source archive preserves unsupported loads, springs, modifiers and other source tables.

Baseline scene construction median was 644 ms in five local CPU runs. Updated median was 52 ms in the final geometry/grid run. Visible objects containing geometry decreased from 9,037 to 3,143. These measurements exclude browser GPU draw time.

Chromium software WebGL was exercised at desktop 1440x1000, mobile portrait 390x844 and landscape 844x390. The final local mobile viewport measured 388x509 in portrait and 634x151 in landscape. Mode switching and source-preserving save were exercised through normal UI controls. The browser import uses the locally generated importer response, with network service verification recorded separately.
