# Python Naming Convention

## Files

snake_case.py

## Modules

Short descriptive names.

## Classes

PascalCase

## Functions

snake_case()

## Variables

snake_case

## Constants

UPPER_CASE

## Engineering Variables

Prefer meaningful names: - axial_force - moment_major -
effective_length - section_area

Avoid unexplained abbreviations.

## Documentation

Keep terminology consistent with the Engineering Calculation
Specification.
