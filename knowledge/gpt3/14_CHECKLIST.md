# Delivery Checklist

## Before Delivery
- Repository inspected
- Duplicate check completed
- Python engine unchanged
- FastAPI integrated
- React connected to real API
- CISC data loaded from approved source
- Report preview implemented
- PDF authorization enforced
- Tests passed
- Production build succeeded
- Documentation updated
- Pull request prepared

- Source code
- Test report
- Deployment notes
- Known limitations
