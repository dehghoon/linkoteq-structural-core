# Linkoteq Structural Core v0.6.0

## Release type

Additive engineering contract release.

Package version: 0.6.0
Existing schema version: 0.5

## Engineering additions

- Joist specifications, including SJI designation,
  analytical representation and capacity status.
- Member-end connections with releases, stiffness
  and offsets.
- Nodal links and multi-point constraints.
- Surface local-axis definitions.
- Extended shell analysis result components.

## Compatibility

Existing Core v0.5 model fields remain supported.

New optional fields do not require existing consumers
to populate them.

No automatic consumer deployment is implied.

## Engineering limitations

Joist capacity must not be treated as verified
without supporting engineering evidence.

Unsupported analysis features must be preserved
and reported rather than silently discarded.

Solver integration and production readiness
require separate verification.
